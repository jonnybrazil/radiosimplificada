# radiosimplificada

Edição estática e simplificada da Radioflat, baseada em GitHub Pages, arquivos de áudio versionados no repositório e configuração remota em JSON via Google Apps Script.

## Direção do projeto

- Frontend público em HTML, CSS e JavaScript;
- Página administrativa `admin.html` para configuração pelo celular;
- Áudios enviados manualmente pelo painel do GitHub;
- Dados de rádio mantidos em um arquivo JSON remoto;
- GOSPELLAB e `radioflat-cms` permanecem separados deste projeto.

## Status

Protótipo inicial — ainda não conectado a uma planilha, Apps Script ou domínio de produção.
